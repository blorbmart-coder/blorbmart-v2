# App screenshots

Every phone on the site renders a coded mockup until a real screenshot is
dropped in here. Name the file after the phone it replaces and it is picked up
automatically on the next build — no code change.

| File name                 | Phone it replaces                       |
| ------------------------- | --------------------------------------- |
| `home.png`                | Hero — buyer app home                   |
| `food.png`                | Food section — live order tracking      |
| `bills.png`               | Bills section — buying airtime          |
| `rider.png`               | Rider section — rider app, online       |
| `vendor.png`              | Vendor section — vendor dashboard       |

`.jpg`, `.jpeg` and `.webp` work too. Use a portrait phone screenshot
(roughly 9:19.5); it is cropped from the top to fit the frame.
