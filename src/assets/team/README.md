# Team photos

Each team badge shows a monogram until a photo is dropped in here. Name the file
after the member's `slug` in `src/content.ts`:

```
oluwabiyi-samuel.jpg      olubodun-bisola.jpg
badmus-qudus.jpg          oyenekwe-chisom.jpg
olaniyan-alexander.jpg    iyanu-olugbenga.jpg
oluwatobi-john.jpg        akinyode-favour.jpg
ayomide-badmus.jpg        akinkunmi-hephzibah.jpg
```

Square photos work best (at least 600 × 600). `.png` and `.webp` work too.
Personal social links go in the same file, under each member's `socials`.
